# 你好,我是 EeeMao 👋

喜欢造一些让「写文档、做实验」更顺手的工具,目前在 VS Code 扩展、Typst 工作流和 AI 辅助工作流之间打转。

## 🛠️ 精选项目

### [Section Figure Paste](https://github.com/EeeMaoY/section-figure-paste)

粘贴图片时**按光标所处章节自动命名**的 VS Code 扩展:在 `=== telnet 命令产生的数据包` 下 Ctrl+V,图片自动存成 `imgs/5.9.1.png`,并在光标处插入 `#image("imgs/5.9.1.png", width: 80%)`。Typst 与 Markdown 双支持,可从 [Releases](https://github.com/EeeMaoY/section-figure-paste/releases) 下载 .vsix 安装。

### [skills](https://github.com/EeeMaoY/skills)

个人的 Claude Code 全局 [skills](https://docs.claude.com/en/docs/claude-code/skills) 集合,放在 `~/.claude/skills/` 下跨机器同步日常沉淀:skill 编写规范、课程实验报告工作流(Typst)等。
